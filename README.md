# OS — Лабораторные работы по операционным системам

Репозиторий содержит решения лабораторных работ по курсу **ОС** на C++ (CMake).
Каждая лабораторная находится в отдельной папке и имеет собственный `README.md` с описанием задания, сборки и запуска.

## Содержание

- [`Kollokvium_1`](./Kollokvium_1) — материалы/задачи к коллоквиуму  
- [`Lab1`](./Lab1) — Лаба 1
- [`Lab2`](./Lab2) — Лаба 2
- [`Lab3`](./Lab3) — Лаба 3
- [`Lab4`](./Lab4) — Лаба 4
- [`Lab5`](./Lab5) — Лаба 5

> В некоторых лабораторных представлены **несколько реализаций одной логики** (например, WinAPI / `std::thread` / Boost).
> Подробности — внутри папки конкретной лабораторной.

## Требования

- Windows 10/11
- CMake (Нужная версия указана для каждой лабы)
- Git (для FetchContent и подтягивания зависимостей, если используется)

Опционально:
- Allure Commandline (если в лабораторной предусмотрена генерация HTML‑отчёта)

## Сборка (типовой сценарий)

Сборка выполняется **внутри папки конкретной лабораторной**.

```bat
cd LabX
mkdir build
cd build
cmake ..
cmake --build .
```

## Запуск

Исполняемые файлы появляются в папке конфигурации сборки (например, `build\Debug`):

```bat
cd build\Debug
.\<имя_программы>.exe
```

## Тесты и отчёты

Если в лабораторной есть автотесты и/или отчёты, команды для запуска и генерации приведены в её `README.md`.
