# Lab4 — Межпроцессное взаимодействие (WinAPI/STDThread)

Лабораторная демонстрирует **обмен сообщениями между процессами** через общий **бинарный файл**.
Процесс **Receiver** создаёт файл и объекты синхронизации, запускает несколько процессов **Sender** и позволяет
по команде читать сообщения из файла.

Используемые объекты WinAPI:

- **Event (`ReadyEvent`)** — сигнал “Receiver готов”, после которого Sender’ы начинают работу.
- **Mutex (`BinaryFileMutex`)** — взаимное исключение при доступе к бинарному файлу.
- **Semaphore (`FreeSlotsSemaphore`)** — количество свободных “слотов” сообщений (ограничение размера буфера).
- **Semaphore (`MessageSemaphore`)** — количество доступных для чтения сообщений.

Также в проекте есть **автотесты (doctest)** и **генерация HTML-отчёта с помощью Allure**.


## Инструкции по сборке

1) Создайте папку `build` и перейдите в неё:

```bat
mkdir build
cd build
```

2) Настройте CMake:

```bat
cmake ..
```

3) Соберите проект:

```bat
cmake --build .
```

> **Требования:** CMake ≥ 3.20, компилятор C++ (C++17), установленный Git (для FetchContent/doctest).  
> **Опционально:** установленный Allure Commandline (для генерации HTML-отчёта).


## Запуск приложения

Важно: **Receiver запускает `Sender.exe` по имени**, поэтому запускайте Receiver из папки, где лежит `Sender.exe`

Пример:

```bat
cd build\Debug
.\Receiver.exe
```

Далее Receiver попросит:
- имя бинарного файла;
- количество записей (размер буфера сообщений);
- количество Sender-процессов.

После запуска Sender’ы будут принимать текст из консоли и записывать сообщения в файл,
а Receiver по команде **Read message** будет читать сообщения в порядке поступления.


## Запуск тестов

Тестовый бинарник собирается как `lab4_tests`.

Пример запуска:

```bat
cd build\Debug
.\lab4_tests.exe
```

## Генерация отчёта Allure

Сборка содержит target’ы для подготовки результатов и генерации отчёта:

```bat
cd build
cmake --build . --target reports
```

После выполнения:
- результаты появляются в папке `Reports`
