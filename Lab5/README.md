# Lab5 — Именованные каналы (WinAPI / Boost)

Лабораторная демонстрирует **межпроцессное взаимодействие** в формате *клиент–сервер*.
Сервер хранит данные о сотрудниках в **бинарном файле** и обслуживает запросы клиентов через
**именованный канал (Named Pipe)**.

Клиентское приложение позволяет:
- **прочитать** запись по `id`;
- **изменить** запись по `id` (с блокировкой записи на время редактирования).

Сервер обеспечивает корректный параллельный доступ: одна и та же запись не может редактироваться несколькими клиентами одновременно,
а чтение/изменение выполняются только через сервер.

В репозитории две реализации одной и той же логики:

- **WinAPI** — IPC и процессы через WinAPI (Named Pipe, запуск процессов и т.д.).
- **Boost** — альтернативная реализация на библиотеке Boost (та же функциональность).

Также в проекте есть **автотесты (Boost.Test)** и **генерация HTML‑отчёта с помощью Allure**.


## Инструкции по сборке

> Ниже показан пример для сборки одной версии. Для второй версии делайте то же самое,
> но из папки соответствующей версии (WinAPI или Boost).

1) Создайте папку `build` и перейдите в неё:

```bat
mkdir build
cd build
```

2) Настройте CMake:

```bat
cmake ..
```

3) Соберите проект:

```bat
cmake --build .
```

> **Требования:** CMake ≥ 3.20, компилятор C++ (C++20/23), установленный Boost (путь к Boost задаётся в `CMakeLists.txt`).  
> **Опционально:** установленный Allure Commandline (для генерации HTML‑отчёта).


## Запуск приложения

Сборка создаёт два исполняемых файла: `Server` и `Client`.

### Server
Запуск из папки конфигурации сборки (например `build\Debug`):

```bat
.\Debug\Server.exe
```

Сервер:
- создаёт/открывает бинарный файл с записями сотрудников;
- поднимает именованный канал (по умолчанию используется имя вроде `EmployeePipe_1`);
- принимает и обрабатывает запросы клиентов на чтение/изменение записей.

### Client

```bat
.\Debug\Client.exe
```

Клиент подключается к серверу и показывает меню команд (чтение/изменение записи по `id`, выход).


## Запуск тестов

Тестовый бинарник собирается как `Lab5Tests`.

Пример запуска:

```bat
.\Debug\Lab5Tests.exe
```


## Генерация отчёта Allure

Сборка содержит target для запуска тестов с выгрузкой результатов и генерации отчёта:

```bat
cmake --build . --target reports
```

После выполнения:
- результаты появляются в папке `Reports`
